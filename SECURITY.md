# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |

## Reporting a Vulnerability

If you discover a security issue in Env Switcher (for example, unexpected
writing of secrets outside the project `.env`, or unsafe handling of profile
values), please **do not** open a public issue.

Prefer one of:

1. GitHub **Private vulnerability reporting** on this repository (Security tab), or
2. Contact the maintainer via https://github.com/SongYuanKun

Please include:

- Plugin / IDE version
- Steps to reproduce
- Impact assessment (what data could leak or be overwritten)

We aim to acknowledge reports within 7 days. This project is volunteer-maintained,
non-commercial open source software; there is no paid security SLA or bug bounty.
